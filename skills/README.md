# Skills Registry

Canonical entry point for reusable capabilities in the Autonomous Course + Reels Revenue Engine.

- `MASTER_SKILLS_2026.md` — governed master pack covering video engineering, agentic systems, infrastructure, continuous learning, software development, engineering, production operations and master orchestration.

## Integration rule

Skills define capability and procedure; they do not bypass `app/policy.py`, durable intent lifecycle, adapter authentication, approval gates or reconciliation. Production implementations should progressively split validated skills into individual versioned skill directories containing instructions, tests/evals, fixtures/references where useful, and explicit success criteria.
