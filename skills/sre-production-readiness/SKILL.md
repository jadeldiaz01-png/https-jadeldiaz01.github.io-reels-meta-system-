# SRE Production Readiness Skill

Evaluate operational readiness using measurable SLO, observability, backup/restore, runbook, capacity and reconciliation evidence.

The skill may produce GO-candidate, CONDITIONAL_GO or NO_GO recommendations but cannot deploy or override production policy. Missing restore or reconciliation evidence is a hard NO_GO.
